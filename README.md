# EV Energy Consumption Prediction

MMA3001 Numerical Methods and Machine Learning, Monash University, 2026.
Individual project by Harshil Dobariya.

## Purpose

This project predicts the energy consumption (kWh/100 mi) of battery electric vehicles on the EPA city (UDDS) and highway (HWFET) test cycles from their design parameters: test mass, rated power, drivetrain and road-load coefficients. Energy consumption is the vehicle-design term that governs driving range, since range is approximately usable battery energy divided by consumption.

Two approaches are compared:

- a physics-based model that numerically integrates tractive power over the EPA drive-cycle speed traces, and
- machine-learning regression models trained on measured EPA test results.

## Usage

Build the cleaned dataset from the raw EPA files:

```bash
python -m ev_energy.data_cleaning
```

This writes two files to `data/processed/` and prints a row count after every cleaning step:

- `ev_clean.csv`: the modelling dataset (712 vehicles), with suspected window-sticker values excluded.
- `ev_clean_with_flagged.csv`: the same plus the 28 flagged vehicles, kept for comparison.

Vehicles reported as whole-number MPGe on both cycles are flagged because this is the format of window-sticker (label) values, which are about 0.7 times the raw test result. This was confirmed against fueleconomy.gov for the 2024 GMC Hummer EV SUV and 2022 Chevrolet Bolt EV.

Run the Stage 2 physics checks, convergence study and figures:

```bash
python scripts/stage2_physics.py
```

Outputs are written to `results/stage2/`.

Run Stage 3 (train/test split, hyperparameter tuning and cross-validated model comparison on the training set):

```bash
python scripts/stage3_models.py
```

Outputs are written to `results/stage3/`. The held-out test set is created and saved here, but is not used for any fitting, tuning or model choice until Stage 4.

Run Stage 4 (final evaluation on the held-out test set, uncertainty, temporal check, sensitivity analysis and comparison with official EPA figures for four well-known EVs):

```bash
python scripts/stage4_validation.py
```

Outputs are written to `results/stage4/`. This is the only stage that uses the test set.

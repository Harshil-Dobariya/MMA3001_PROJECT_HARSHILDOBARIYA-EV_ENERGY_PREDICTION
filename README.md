MMA3001 Numerical Methods and Machine Learning, Monash University, 2026.
Project by Harshil Dobariya.

## Purpose

This project predicts the energy consumption (kWh/100 mi) of battery electric vehicles on the EPA city (UDDS) and highway (HWFET) test cycles from their design parameters: test mass, rated power, drivetrain and road-load coefficients. Energy consumption is the vehicle-design term that governs driving range, since range is approximately usable battery energy divided by consumption.

Two approaches are compared:

- a physics-based model that numerically integrates tractive power over the EPA drive-cycle speed traces, and
- machine-learning regression models trained on measured EPA test results.

## Data

| Source | Use | Location |
|---|---|---|
| US EPA, [Data on Cars Used for Testing Fuel Economy](https://www.epa.gov/compliance-and-fuel-economy-data/data-cars-used-testing-fuel-economy), model years 2022 to 2026 | Vehicle inputs and measured consumption | `data/raw/*testcar*.xlsx` |
| US EPA, [Dynamometer Drive Schedules](https://epa.gov/vehicle-and-fuel-emissions-testing/dynamometer-drive-schedules) | UDDS and HWFET speed-time traces | `data/raw/` |

Both are US Government public data.

## Setup

Requires Python 3.10 or later.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
```

## Usage

Build the cleaned dataset from the raw EPA files:

```bash
python -m ev_energy.data_cleaning
```

This writes `data/processed/ev_clean.csv` and prints a row count after every cleaning step.

## Testing

```bash
pytest
```

Runs all unit tests and the docstring examples.

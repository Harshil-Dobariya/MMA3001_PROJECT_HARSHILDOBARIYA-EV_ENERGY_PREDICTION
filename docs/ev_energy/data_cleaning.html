ev_energy.data_cleaning

Load and clean EPA test car data for battery electric vehicles.

This module turns the raw EPA "Data on Cars Used for Testing Fuel Economy" spreadsheets into one tidy table with one row per tested vehicle configuration, holding its design inputs and its measured city (UDDS) and highway (HWFET) energy consumption.

Source data

US EPA, Data on Cars Used for Testing Fuel Economy, model years 2022-2026. https://www.epa.gov/compliance-and-fuel-economy-data/data-cars-used-testing-fuel-economy

Pipeline (see clean_ev_dataframe())

  1. Keep only electricity-fuelled charge-depleting UDDS and Highway tests.
  2. Rename columns to short snake_case names.
  3. Standardise manufacturer brand names.
  4. Convert the reported efficiency to a single unit (kWh/100 mi).
  5. Reject physically invalid inputs (e.g. placeholder horsepower).
  6. Average repeated tests of the same vehicle on the same cycle.
  7. Pivot so each vehicle has both a city and a highway result.
  8. Add SI-unit versions of mass and road-load coefficients.
  9. Apply physical plausibility limits.
  10. Flag (and by default exclude) suspected window-sticker values.
  11. Add a group identifier for leakage-safe train/test splitting.

Every step records how many rows remain, so data losses are traceable.

Notes on the raw efficiency field

For EVs, RND_ADJ_FE is labelled "MPG" but manufacturers report it inconsistently. Most report unadjusted MPGe (typically 70 to 200), while some (e.g. Hyundai, Kia, Genesis, Rivian) report kWh/100 mi (typically 15 to 40). Values of 999 and other values above 500 are placeholders. The unit is therefore inferred from magnitude, see to_kwh_per_100mi().

Suspected window-sticker values

Some vehicles are reported as whole-number MPGe on both cycles. A physics cross-check (Stage 2) showed most of these sit about 1.3 times above the physics prediction, the signature of label (adjusted) values, which are roughly 0.7 times the raw test result. This was confirmed against fueleconomy.gov: the 2024 GMC Hummer EV SUV versions report 59/48, 56/46 and 51/43 MPGe city/highway in both sources, and the 2022 Chevrolet Bolt EV label (131/109) matches the data (129 and 132 / 109) within 2 MPGe. Such vehicles are flagged by how their values were reported, not by model residuals, see is_whole_number_mpge().

175def load_raw_files(paths: Iterable[str | Path]) -> pd.DataFrame:
176    """Load and concatenate raw EPA test car spreadsheets.
177
178    Parameters
179    ----------
180    paths : iterable of str or pathlib.Path
181        Paths to the EPA ``.xlsx`` (or ``.csv``) files, one per model year.
182
183    Returns
184    -------
185    pandas.DataFrame
186        All rows from all files, with an added ``source_file`` column.
187
188    Raises
189    ------
190    ValueError
191        If no paths are given, or a file is missing a required column.
192    FileNotFoundError
193        If a path does not exist.
194    """
195    paths = [Path(p) for p in paths]
196    if not paths:
197        raise ValueError("No input files given.")
198
199    frames = []
200    for path in paths:
201        if not path.exists():
202            raise FileNotFoundError(f"Input file not found: {path}")
203        if path.suffix.lower() == ".csv":
204            frame = pd.read_csv(path)
205        else:
206            frame = pd.read_excel(path)
207        missing = [c for c in REQUIRED_RAW_COLUMNS if c not in frame.columns]
208        if missing:
209            raise ValueError(f"{path.name} is missing required columns: {missing}")
210        frame["source_file"] = path.name
211        frames.append(frame)
212
213    return pd.concat(frames, ignore_index=True)

221def select_ev_cd_tests(raw: pd.DataFrame) -> pd.DataFrame:
222    """Keep only electric charge-depleting city and highway test rows.
223
224    Parameters
225    ----------
226    raw : pandas.DataFrame
227        Raw EPA rows with original column names.
228
229    Returns
230    -------
231    pandas.DataFrame
232        Rows whose fuel is electricity and whose procedure is the
233        charge-depleting UDDS or Highway test, with columns renamed to the
234        project's snake_case names and a ``cycle`` column (``"city"`` or
235        ``"hwy"``) added.
236    """
237    is_ev = raw["Test Fuel Type Description"] == EV_FUEL_DESCRIPTION
238    is_cd = raw["Test Procedure Description"].isin([CITY_PROCEDURE, HIGHWAY_PROCEDURE])
239    selected = raw.loc[is_ev & is_cd, list(RAW_TO_CLEAN_COLUMNS)].rename(
240        columns=RAW_TO_CLEAN_COLUMNS
241    )
242    selected["cycle"] = np.where(selected["procedure"] == CITY_PROCEDURE, "city", "hwy")
243    return selected.reset_index(drop=True)

246def standardise_make(make: object, manufacturer: object) -> str | float:
247    """Return a consistent brand name for one row.
248
249    Parameters
250    ----------
251    make : object
252        Raw ``Represented Test Veh Make`` value.
253    manufacturer : object
254        Raw ``Vehicle Manufacturer Name`` value, used as a fallback when the
255        make field holds a year (e.g. ``"2024"``) instead of a brand.
256
257    Returns
258    -------
259    str or float
260        Standardised brand name, or ``numpy.nan`` if it cannot be resolved.
261
262    Examples
263    --------
264    >>> standardise_make("AUDI", "Volkswagen Group of")
265    'Audi'
266    >>> standardise_make(2024, "Lucid USA, Inc")
267    'Lucid'
268    """
269    if pd.isna(make):
270        return np.nan
271    make_str = str(make).strip()
272    if make_str.isdigit():
273        return MANUFACTURER_TO_MAKE.get(str(manufacturer).strip(), np.nan)
274    return MAKE_ALIASES.get(make_str, make_str)

277def to_kwh_per_100mi(value: float) -> float:
278    """Convert one reported EV efficiency value to kWh/100 mi.
279
280    The unit is inferred from magnitude because manufacturers report the
281    same field in different units:
282
283    * ``value >= SENTINEL_THRESHOLD``: placeholder, returns NaN.
284    * ``value < KWH_UNIT_THRESHOLD``: already kWh/100 mi, returned as is.
285    * otherwise: unadjusted MPGe, converted with
286      ``kWh/100 mi = 100 * 33.705 / MPGe``.
287
288    Parameters
289    ----------
290    value : float
291        Reported ``RND_ADJ_FE`` value.
292
293    Returns
294    -------
295    float
296        Energy consumption in kWh/100 mi, or ``numpy.nan`` if invalid.
297
298    Examples
299    --------
300    >>> round(to_kwh_per_100mi(100.0), 3)
301    33.705
302    >>> to_kwh_per_100mi(25.0)
303    25.0
304    >>> import math; math.isnan(to_kwh_per_100mi(999.0))
305    True
306    """
307    if value is None or not np.isfinite(value) or value <= 0:
308        return np.nan
309    if value >= SENTINEL_THRESHOLD:
310        return np.nan
311    if value < KWH_UNIT_THRESHOLD:
312        return float(value)
313    return 100.0 * KWH_PER_GALLON_EQUIVALENT / float(value)

316def reported_unit(value: float) -> str:
317    """Label the unit inferred for one reported efficiency value.
318
319    Parameters
320    ----------
321    value : float
322        Reported ``RND_ADJ_FE`` value.
323
324    Returns
325    -------
326    str
327        ``"kWh/100mi"``, ``"MPGe"`` or ``"invalid"``.
328    """
329    if value is None or not np.isfinite(value) or value <= 0 or value >= SENTINEL_THRESHOLD:
330        return "invalid"
331    return "kWh/100mi" if value < KWH_UNIT_THRESHOLD else "MPGe"

334def is_whole_number_mpge(value: float) -> bool:
335    """Return True if a reported value is MPGe and a whole number.
336
337    Raw dynamometer results are normally reported to one decimal place.
338    Whole-number MPGe values are the format of window-sticker (label)
339    values, so they mark a vehicle for checking.
340
341    Parameters
342    ----------
343    value : float
344        Reported ``RND_ADJ_FE`` value.
345
346    Returns
347    -------
348    bool
349        True if the value is interpreted as MPGe and has no fractional part.
350
351    Examples
352    --------
353    >>> is_whole_number_mpge(109.0)
354    True
355    >>> is_whole_number_mpge(184.5)
356    False
357    >>> is_whole_number_mpge(25.0)   # kWh/100 mi, not MPGe
358    False
359    """
360    if reported_unit(value) != "MPGe":
361        return False
362    return bool(np.isclose(value, round(value), atol=1e-6))

365def aggregate_repeat_tests(tests: pd.DataFrame) -> pd.DataFrame:
366    """Average repeated tests of the same vehicle on the same cycle.
367
368    Some vehicles were tested more than once on a cycle (e.g. the 2022
369    Chevrolet Bolt EUV). The mean is kept as the measured value, and the
370    count and standard deviation are kept as evidence of test-to-test
371    repeatability.
372
373    Parameters
374    ----------
375    tests : pandas.DataFrame
376        One row per individual test, with ``kwh_per_100mi`` filled in.
377
378    Returns
379    -------
380    pandas.DataFrame
381        One row per vehicle configuration and cycle, with columns
382        ``kwh_per_100mi`` (mean), ``n_tests``, ``kwh_std`` and
383        ``whole_mpge`` (True if every test was reported as whole-number
384        MPGe).
385    """
386    keys = VEHICLE_KEY + SPEC_COLUMNS + ["cycle"]
387    grouped = tests.groupby(keys, dropna=False)
388    return grouped.agg(
389        kwh_per_100mi=("kwh_per_100mi", "mean"),
390        n_tests=("kwh_per_100mi", "count"),
391        kwh_std=("kwh_per_100mi", "std"),
392        whole_mpge=("whole_mpge", "all"),
393    ).reset_index()

396def pivot_cycles(per_cycle: pd.DataFrame) -> pd.DataFrame:
397    """Reshape to one row per vehicle with city and highway columns.
398
399    Vehicles without a valid result on both cycles are dropped.
400
401    Parameters
402    ----------
403    per_cycle : pandas.DataFrame
404        Output of :func:`aggregate_repeat_tests`.
405
406    Returns
407    -------
408    pandas.DataFrame
409        Columns ``city_kwh_per_100mi``, ``hwy_kwh_per_100mi``,
410        ``city_n_tests``, ``hwy_n_tests``, ``city_kwh_std`` and
411        ``hwy_kwh_std``, ``city_whole_mpge`` and ``hwy_whole_mpge``
412        alongside the vehicle key and spec columns.
413    """
414    index = VEHICLE_KEY + SPEC_COLUMNS
415    values = ["kwh_per_100mi", "n_tests", "kwh_std", "whole_mpge"]
416    halves = []
417    for cycle in ("city", "hwy"):
418        half = per_cycle.loc[per_cycle["cycle"] == cycle, index + values]
419        halves.append(half.rename(columns={v: f"{cycle}_{v}" for v in values}))
420    # An inner merge keeps only vehicles with a result on both cycles.
421    wide = halves[0].merge(halves[1], on=index, how="inner")
422    wide = wide.dropna(subset=["city_kwh_per_100mi", "hwy_kwh_per_100mi"])
423    return wide.reset_index(drop=True)

426def add_si_units(vehicles: pd.DataFrame) -> pd.DataFrame:
427    """Add SI versions of test mass and road-load coefficients.
428
429    The EPA road-load force is ``F(v) = A + B v + C v**2`` with ``F`` in lbf
430    and ``v`` in mph. In SI form, ``F(v) = f0 + f1 v + f2 v**2`` with ``F``
431    in N and ``v`` in m/s, where
432
433    * ``f0 = A * N_PER_LBF``                    [N]
434    * ``f1 = B * N_PER_LBF / MPS_PER_MPH``      [N/(m/s)]
435    * ``f2 = C * N_PER_LBF / MPS_PER_MPH**2``   [N/(m/s)^2]
436
437    Parameters
438    ----------
439    vehicles : pandas.DataFrame
440        Table with ``etw_lb`` and the three ``coef_*`` columns.
441
442    Returns
443    -------
444    pandas.DataFrame
445        Copy with ``etw_kg``, ``f0_n``, ``f1_n_per_mps`` and
446        ``f2_n_per_mps2`` added.
447    """
448    out = vehicles.copy()
449    out["etw_kg"] = out["etw_lb"] * KG_PER_LB
450    out["f0_n"] = out["coef_a_lbf"] * N_PER_LBF
451    out["f1_n_per_mps"] = out["coef_b_lbf_per_mph"] * N_PER_LBF / MPS_PER_MPH
452    out["f2_n_per_mps2"] = out["coef_c_lbf_per_mph2"] * N_PER_LBF / MPS_PER_MPH**2
453    return out

456def road_load_lbf(vehicles: pd.DataFrame, speed_mph: float) -> pd.Series:
457    """Evaluate the road-load force ``A + B v + C v**2`` at one speed.
458
459    Parameters
460    ----------
461    vehicles : pandas.DataFrame
462        Table with the three ``coef_*`` columns.
463    speed_mph : float
464        Vehicle speed in mph.
465
466    Returns
467    -------
468    pandas.Series
469        Road-load force in lbf for each row.
470    """
471    v = speed_mph
472    return (
473        vehicles["coef_a_lbf"]
474        + vehicles["coef_b_lbf_per_mph"] * v
475        + vehicles["coef_c_lbf_per_mph2"] * v**2
476    )

479def make_group_id(make: str, model: str) -> str:
480    """Build a group identifier shared by all years of one vehicle model.
481
482    The same model is often retested with an identical specification in
483    later model years. Splitting by this identifier keeps every copy of a
484    model on one side of a train/test split, preventing data leakage.
485
486    Parameters
487    ----------
488    make : str
489        Standardised brand name.
490    model : str
491        Raw model name.
492
493    Returns
494    -------
495    str
496        Lower-case ``"make|model"`` with whitespace collapsed.
497
498    Examples
499    --------
500    >>> make_group_id("Tesla", "Model 3  Long Range AWD")
501    'tesla|model 3 long range awd'
502    """
503    text = f"{make}|{model}".lower()
504    return " ".join(text.split())

512def clean_ev_dataframe(
513    raw: pd.DataFrame, exclude_label_values: bool = True
514) -> tuple[pd.DataFrame, dict[str, int]]:
515    """Run the full cleaning pipeline on raw EPA rows.
516
517    Parameters
518    ----------
519    raw : pandas.DataFrame
520        Raw EPA rows with original column names (e.g. from
521        :func:`load_raw_files`).
522    exclude_label_values : bool, optional
523        If True (default), drop vehicles reported as whole-number MPGe on
524        both cycles (suspected window-sticker values). If False, keep them
525        and mark them in the ``label_value_suspect`` column.
526
527    Returns
528    -------
529    vehicles : pandas.DataFrame
530        One row per tested vehicle configuration with both cycle results.
531    report : dict of str to int
532        Row count after each step, in order, for the documentation.
533
534    Raises
535    ------
536    ValueError
537        If a required raw column is missing.
538    """
539    missing = [c for c in REQUIRED_RAW_COLUMNS if c not in raw.columns]
540    if missing:
541        raise ValueError(f"Raw data is missing required columns: {missing}")
542
543    report: dict[str, int] = {"raw rows (all fuels and procedures)": len(raw)}
544
545    tests = select_ev_cd_tests(raw)
546    report["EV charge-depleting city/highway test rows"] = len(tests)
547
548    tests["make"] = [
549        standardise_make(m, f) for m, f in zip(tests["make"], tests["manufacturer"])
550    ]
551    tests = tests.dropna(subset=["make"])
552    report["rows with a resolvable brand"] = len(tests)
553
554    tests["fe_unit_inferred"] = tests["fe_reported"].apply(reported_unit)
555    tests["kwh_per_100mi"] = tests["fe_reported"].apply(to_kwh_per_100mi)
556    tests["whole_mpge"] = tests["fe_reported"].apply(is_whole_number_mpge)
557    tests = tests.dropna(subset=["kwh_per_100mi"])
558    report["rows with a valid efficiency value (sentinels removed)"] = len(tests)
559
560    tests.loc[tests["rated_hp"] < MIN_PLAUSIBLE_HP, "rated_hp"] = np.nan
561    tests = tests.dropna(subset=SPEC_COLUMNS[2:])
562    report["rows with complete, plausible design inputs"] = len(tests)
563
564    per_cycle = aggregate_repeat_tests(tests)
565    report["vehicle-cycle results after averaging repeat tests"] = len(per_cycle)
566
567    vehicles = pivot_cycles(per_cycle)
568    report["vehicles with both city and highway results"] = len(vehicles)
569
570    vehicles = add_si_units(vehicles)
571
572    consumption = vehicles[["city_kwh_per_100mi", "hwy_kwh_per_100mi"]]
573    in_range = consumption.apply(
574        lambda s: s.between(MIN_PLAUSIBLE_KWH_PER_100MI, MAX_PLAUSIBLE_KWH_PER_100MI)
575    ).all(axis=1)
576    positive_load = road_load_lbf(vehicles, ROAD_LOAD_CHECK_SPEED_MPH) > 0
577    vehicles = vehicles[in_range & positive_load].reset_index(drop=True)
578    report["vehicles passing physical plausibility checks"] = len(vehicles)
579
580    vehicles["label_value_suspect"] = vehicles["city_whole_mpge"] & vehicles["hwy_whole_mpge"]
581    vehicles = vehicles.drop(columns=["city_whole_mpge", "hwy_whole_mpge"])
582    if exclude_label_values:
583        vehicles = vehicles[~vehicles["label_value_suspect"]].reset_index(drop=True)
584        report["vehicles after excluding suspected window-sticker values"] = len(vehicles)
585
586    vehicles["group_id"] = [
587        make_group_id(m, n) for m, n in zip(vehicles["make"], vehicles["model"])
588    ]
589    vehicles["model_year"] = vehicles["model_year"].astype(int)
590    vehicles = vehicles.sort_values(VEHICLE_KEY).reset_index(drop=True)
591    return vehicles, report

427def add_si_units(vehicles: pd.DataFrame) -> pd.DataFrame:
428    """Add SI versions of test mass and road-load coefficients.
429
430    The EPA road-load force is ``F(v) = A + B v + C v**2`` with ``F`` in lbf
431    and ``v`` in mph. In SI form, ``F(v) = f0 + f1 v + f2 v**2`` with ``F``
432    in N and ``v`` in m/s, where
433
434    * ``f0 = A * N_PER_LBF``                    [N]
435    * ``f1 = B * N_PER_LBF / MPS_PER_MPH``      [N/(m/s)]
436    * ``f2 = C * N_PER_LBF / MPS_PER_MPH**2``   [N/(m/s)^2]
437
438    Parameters
439    ----------
440    vehicles : pandas.DataFrame
441        Table with ``etw_lb`` and the three ``coef_*`` columns.
442
443    Returns
444    -------
445    pandas.DataFrame
446        Copy with ``etw_kg``, ``f0_n``, ``f1_n_per_mps`` and
447        ``f2_n_per_mps2`` added.
448    """
449    out = vehicles.copy()
450    out["etw_kg"] = out["etw_lb"] * KG_PER_LB
451    out["f0_n"] = out["coef_a_lbf"] * N_PER_LBF
452    out["f1_n_per_mps"] = out["coef_b_lbf_per_mph"] * N_PER_LBF / MPS_PER_MPH
453    out["f2_n_per_mps2"] = out["coef_c_lbf_per_mph2"] * N_PER_LBF / MPS_PER_MPH**2
454    return out

521        Raw EPA rows with original column names (e.g. from
522        :func:`load_raw_files`).
523    exclude_label_values : bool, optional
524        If True (default), drop vehicles reported as whole-number MPGe on
525        both cycles (suspected window-sticker values). If False, keep them
526        and mark them in the ``label_value_suspect`` column.
527
528    Returns
529    -------
530    vehicles : pandas.DataFrame
531        One row per tested vehicle configuration with both cycle results.
532    report : dict of str to int
533        Row count after each step, in order, for the documentation.
534
535    Raises
536    ------
537    ValueError
538        If a required raw column is missing.
539    """
540    missing = [c for c in REQUIRED_RAW_COLUMNS if c not in raw.columns]
541    if missing:
542        raise ValueError(f"Raw data is missing required columns: {missing}")
543
544    report: dict[str, int] = {"raw rows (all fuels and procedures)": len(raw)}
545
546    tests = select_ev_cd_tests(raw)
547    report["EV charge-depleting city/highway test rows"] = len(tests)
548
549    tests["make"] = [
550        standardise_make(m, f) for m, f in zip(tests["make"], tests["manufacturer"])
551    ]
552    tests = tests.dropna(subset=["make"])
553    report["rows with a resolvable brand"] = len(tests)
554
555    tests["fe_unit_inferred"] = tests["fe_reported"].apply(reported_unit)
556    tests["kwh_per_100mi"] = tests["fe_reported"].apply(to_kwh_per_100mi)
557    tests["whole_mpge"] = tests["fe_reported"].apply(is_whole_number_mpge)
558    tests = tests.dropna(subset=["kwh_per_100mi"])
559    report["rows with a valid efficiency value (sentinels removed)"] = len(tests)
560
561    tests.loc[tests["rated_hp"] < MIN_PLAUSIBLE_HP, "rated_hp"] = np.nan
562    tests = tests.dropna(subset=SPEC_COLUMNS[2:])
563    report["rows with complete, plausible design inputs"] = len(tests)
564
565    per_cycle = aggregate_repeat_tests(tests)
566    report["vehicle-cycle results after averaging repeat tests"] = len(per_cycle)
567
568    vehicles = pivot_cycles(per_cycle)
569    report["vehicles with both city and highway results"] = len(vehicles)
570
571    vehicles = add_si_units(vehicles)
572
573    consumption = vehicles[["city_kwh_per_100mi", "hwy_kwh_per_100mi"]]
574    in_range = consumption.apply(
575        lambda s: s.between(MIN_PLAUSIBLE_KWH_PER_100MI, MAX_PLAUSIBLE_KWH_PER_100MI)
576    ).all(axis=1)
577    positive_load = road_load_lbf(vehicles, ROAD_LOAD_CHECK_SPEED_MPH) > 0
578    vehicles = vehicles[in_range & positive_load].reset_index(drop=True)
579    report["vehicles passing physical plausibility checks"] = len(vehicles)
580
581    vehicles["label_value_suspect"] = vehicles["city_whole_mpge"] & vehicles["hwy_whole_mpge"]
582    vehicles = vehicles.drop(columns=["city_whole_mpge", "hwy_whole_mpge"])
583    if exclude_label_values:
584        vehicles = vehicles[~vehicles["label_value_suspect"]].reset_index(drop=True)
585        report["vehicles after excluding suspected window-sticker values"] = len(vehicles)
586
587    vehicles["group_id"] = [
588        make_group_id(m, n) for m, n in zip(vehicles["make"], vehicles["model"])
589    ]
590    vehicles["model_year"] = vehicles["model_year"].astype(int)
591    vehicles = vehicles.sort_values(VEHICLE_KEY).reset_index(drop=True)
592    return vehicles, report

ev_energy.physics_model

Physics-based EV energy consumption model integrated over EPA drive cycles.

Model (agreed form)

Longitudinal dynamics on a flat dynamometer:

m a(t) = F_t(t) - F_RL(v(t)),   F_RL(v) = f0 + f1 v + f2 v**2

Wheel power:

P_w(t) = F_t(t) v(t) = [m a(t) + f0 + f1 v(t) + f2 v(t)**2] v(t)

Wall energy over one cycle of duration T:

E_b = E_pos / eta_d - eta_r * E_neg + P_aux * T

where

E_pos = integral of max(P_w, 0) dt    (driving energy at the wheels)
E_neg = integral of max(-P_w, 0) dt   (braking energy available)

and consumption is c = E_b / D with D = integral of v dt.

Symbols

m : equivalent test weight [kg] v, a : speed [m/s] and acceleration [m/s^2] from the drive-cycle trace f0 : constant road-load term [N] f1 : linear road-load term [N/(m/s)] f2 : quadratic road-load term [N/(m/s)^2] eta_d : wall-to-wheel efficiency when driving [-] eta_r : fraction of braking energy recovered [-] P_aux : constant accessory power [W]

Because c is linear in k1 = 1/eta_d, k2 = eta_r and k3 = P_aux, the three parameters are fitted by bounded linear least squares (PhysicsModel).

Numerical methods
  • Acceleration: second-order central finite differences in the interior, first-order one-sided differences at the two end points (finite_difference_acceleration()).
  • Integration: composite trapezoidal rule (trapezoid()) and composite Simpson's rule with a 3/8 correction for an odd number of intervals (simpson()).

 90@dataclass(frozen=True)
 91class DriveCycle:
 92    """A speed-time trace sampled at a uniform time step.
 93
 94    Attributes
 95    ----------
 96    name : str
 97        Short name, e.g. ``"city"`` or ``"hwy"``.
 98    time_s : numpy.ndarray
 99        Time stamps in seconds, uniformly spaced, starting at 0.
100    speed_mps : numpy.ndarray
101        Target speed in m/s at each time stamp.
102    """
103
104    name: str
105    time_s: np.ndarray
106    speed_mps: np.ndarray
107
108    @property
109    def dt(self) -> float:
110        """Time step in seconds."""
111        return float(self.time_s[1] - self.time_s[0])
112
113    @property
114    def duration_s(self) -> float:
115        """Total cycle duration in seconds."""
116        return float(self.time_s[-1] - self.time_s[0])
117
118    def subsample(self, step: int) -> "DriveCycle":
119        """Return the cycle keeping every ``step``-th sample.
120
121        Used for the step-size convergence study. The last sample is always
122        kept so the cycle duration is unchanged where possible.
123
124        Parameters
125        ----------
126        step : int
127            Keep one sample in every ``step``. Must be at least 1.
128
129        Returns
130        -------
131        DriveCycle
132            Coarser cycle with time step ``step * dt``.
133        """
134        if step < 1:
135            raise ValueError("step must be at least 1.")
136        idx = np.arange(0, len(self.time_s), step)
137        return DriveCycle(self.name, self.time_s[idx], self.speed_mps[idx])
138
139    def refine(self, factor: int, kind: str = "linear") -> "DriveCycle":
140        """Return the cycle resampled at ``dt / factor`` by interpolation.
141
142        Used for the step-size convergence study. EPA only publishes the
143        trace at 1 s, so values between samples must be assumed. Two
144        interpolants are offered so their effect can be compared:
145
146        * ``"linear"``: straight lines between samples.
147        * ``"pchip"``: shape-preserving cubic (PCHIP). Unlike a standard
148          cubic spline it cannot overshoot, so speed never goes negative.
149
150        Parameters
151        ----------
152        factor : int
153            Refinement factor, at least 1. ``factor=4`` gives 0.25 s steps.
154        kind : {"linear", "pchip"}
155            Interpolant used between the original samples.
156
157        Returns
158        -------
159        DriveCycle
160            Finer cycle covering the same time span.
161        """
162        if factor < 1:
163            raise ValueError("factor must be at least 1.")
164        n_new = (len(self.time_s) - 1) * factor + 1
165        t_new = np.linspace(self.time_s[0], self.time_s[-1], n_new)
166        if kind == "linear":
167            v_new = np.interp(t_new, self.time_s, self.speed_mps)
168        elif kind == "pchip":
169            v_new = PchipInterpolator(self.time_s, self.speed_mps)(t_new)
170        else:
171            raise ValueError("kind must be 'linear' or 'pchip'.")
172        return DriveCycle(self.name, t_new, v_new)

175def load_drive_cycle(path: str | Path, name: str) -> DriveCycle:
176    """Load an EPA drive-cycle text file (time in s, speed in mph).
177
178    The EPA files have two header lines followed by tab-separated columns.
179
180    Parameters
181    ----------
182    path : str or pathlib.Path
183        Path to the EPA ``.txt`` file.
184    name : str
185        Short name for the cycle.
186
187    Returns
188    -------
189    DriveCycle
190        Cycle with speed converted to m/s.
191
192    Raises
193    ------
194    FileNotFoundError
195        If the file does not exist.
196    ValueError
197        If the time step is not uniform, or any speed is negative.
198    """
199    path = Path(path)
200    if not path.exists():
201        raise FileNotFoundError(f"Drive cycle file not found: {path}")
202    data = np.loadtxt(path, skiprows=2)
203    time_s, speed_mph = data[:, 0], data[:, 1]
204    steps = np.diff(time_s)
205    if not np.allclose(steps, steps[0]):
206        raise ValueError(f"{path.name}: time step is not uniform.")
207    if np.any(speed_mph < 0):
208        raise ValueError(f"{path.name}: negative speeds found.")
209    return DriveCycle(name, time_s, speed_mph * MPS_PER_MPH)

237def finite_difference_acceleration(speed: np.ndarray, dt: float) -> np.ndarray:
238    """Differentiate a uniformly sampled speed trace.
239
240    Interior points use the second-order central difference
241    ``a_i = (v_{i+1} - v_{i-1}) / (2 dt)``. The first and last points use
242    first-order forward and backward differences.
243
244    Parameters
245    ----------
246    speed : numpy.ndarray
247        Speed samples, shape ``(n,)`` with ``n >= 2``.
248    dt : float
249        Time step.
250
251    Returns
252    -------
253    numpy.ndarray
254        Acceleration at every sample, shape ``(n,)``.
255
256    Examples
257    --------
258    >>> finite_difference_acceleration(np.array([0.0, 1.0, 4.0, 9.0]), 1.0)
259    array([1., 2., 4., 5.])
260    """
261    speed = np.asarray(speed, dtype=float)
262    if speed.size < 2:
263        raise ValueError("Need at least two samples to differentiate.")
264    accel = np.empty_like(speed)
265    accel[1:-1] = (speed[2:] - speed[:-2]) / (2.0 * dt)
266    accel[0] = (speed[1] - speed[0]) / dt
267    accel[-1] = (speed[-1] - speed[-2]) / dt
268    return accel

271def trapezoid(y: np.ndarray, dt: float) -> np.ndarray:
272    """Composite trapezoidal rule along the last axis.
273
274    ``I = dt * (y_0 / 2 + y_1 + ... + y_{n-2} + y_{n-1} / 2)``
275
276    Parameters
277    ----------
278    y : numpy.ndarray
279        Samples at uniform spacing, shape ``(..., n)``.
280    dt : float
281        Sample spacing.
282
283    Returns
284    -------
285    numpy.ndarray
286        Integral along the last axis.
287
288    Examples
289    --------
290    >>> float(trapezoid(np.array([0.0, 1.0, 2.0]), 1.0))
291    2.0
292    """
293    y = np.asarray(y, dtype=float)
294    return dt * (y[..., 1:-1].sum(axis=-1) + 0.5 * (y[..., 0] + y[..., -1]))
295
296
297def _simpson_13(y: np.ndarray, dt: float) -> np.ndarray:
298    """Composite Simpson's 1/3 rule for an even number of intervals."""
299    return dt / 3.0 * (
300        y[..., 0] + y[..., -1]
301        + 4.0 * y[..., 1:-1:2].sum(axis=-1)
302        + 2.0 * y[..., 2:-1:2].sum(axis=-1)
303    )
304
305
306def _simpson_38(y: np.ndarray, dt: float) -> np.ndarray:
307    """Simpson's 3/8 rule over exactly three intervals (four points)."""
308    return 3.0 * dt / 8.0 * (y[..., 0] + 3.0 * y[..., 1] + 3.0 * y[..., 2] + y[..., 3])
309
310
311def simpson(y: np.ndarray, dt: float) -> np.ndarray:
312    """Composite Simpson's rule along the last axis.
313
314    With an even number of intervals the 1/3 rule is used throughout. With
315    an odd number (as in both EPA cycles: 1369 and 765 intervals), the 1/3
316    rule covers all but the last three intervals, and the 3/8 rule covers
317    those three. Both rules are fourth-order accurate for smooth integrands.
318
319    Parameters
320    ----------
321    y : numpy.ndarray
322        Samples at uniform spacing, shape ``(..., n)`` with ``n >= 3``.
323    dt : float
324        Sample spacing.
325
326    Returns
327    -------
328    numpy.ndarray
329        Integral along the last axis.
330
331    Examples
332    --------
333    >>> x = np.linspace(0.0, 1.0, 5)       # 4 intervals, even
334    >>> round(float(simpson(x**3, 0.25)), 12)
335    0.25
336    >>> x = np.linspace(0.0, 1.0, 6)       # 5 intervals, odd
337    >>> round(float(simpson(x**3, 0.2)), 12)
338    0.25
339    """
340    y = np.asarray(y, dtype=float)
341    n_intervals = y.shape[-1] - 1
342    if n_intervals < 2:
343        raise ValueError("Simpson's rule needs at least two intervals.")
344    if n_intervals % 2 == 0:
345        return _simpson_13(y, dt)
346    if n_intervals == 3:
347        return _simpson_38(y, dt)
348    return _simpson_13(y[..., :-3], dt) + _simpson_38(y[..., -4:], dt)
349
350
351def integrate(y: np.ndarray, dt: float, method: str = "trapezoid") -> np.ndarray:
352    """Integrate uniformly sampled data with the chosen rule.
353
354    Parameters
355    ----------
356    y : numpy.ndarray
357        Samples, shape ``(..., n)``.
358    dt : float
359        Sample spacing.
360    method : {"trapezoid", "simpson"}
361        Integration rule.
362
363    Returns
364    -------
365    numpy.ndarray
366        Integral along the last axis.
367    """
368    if method == "trapezoid":
369        return trapezoid(y, dt)
370    if method == "simpson":
371        return simpson(y, dt)
372    raise ValueError(f"Unknown method {method!r}; choose from {INTEGRATORS}.")

380def wheel_power(
381    speed: np.ndarray,
382    accel: np.ndarray,
383    mass_kg: np.ndarray,
384    f0: np.ndarray,
385    f1: np.ndarray,
386    f2: np.ndarray,
387) -> np.ndarray:
388    """Wheel power ``P_w = (m a + f0 + f1 v + f2 v^2) v`` for many vehicles.
389
390    Parameters
391    ----------
392    speed, accel : numpy.ndarray
393        Cycle speed [m/s] and acceleration [m/s^2], shape ``(n_time,)``.
394    mass_kg, f0, f1, f2 : numpy.ndarray
395        Vehicle parameters, shape ``(n_vehicles,)``.
396
397    Returns
398    -------
399    numpy.ndarray
400        Wheel power in W, shape ``(n_vehicles, n_time)``.
401    """
402    v = np.asarray(speed, dtype=float)[None, :]
403    a = np.asarray(accel, dtype=float)[None, :]
404    m = np.asarray(mass_kg, dtype=float)[:, None]
405    f0 = np.asarray(f0, dtype=float)[:, None]
406    f1 = np.asarray(f1, dtype=float)[:, None]
407    f2 = np.asarray(f2, dtype=float)[:, None]
408    return (m * a + f0 + f1 * v + f2 * v**2) * v

411def cycle_energy_terms(
412    cycle: DriveCycle,
413    mass_kg: np.ndarray,
414    f0: np.ndarray,
415    f1: np.ndarray,
416    f2: np.ndarray,
417    method: str = "trapezoid",
418    chunk_size: int | None = DEFAULT_CHUNK_SIZE,
419) -> dict[str, np.ndarray]:
420    """Compute the physics terms of the energy model for one cycle.
421
422    Parameters
423    ----------
424    cycle : DriveCycle
425        Drive cycle to integrate over.
426    mass_kg, f0, f1, f2 : numpy.ndarray
427        Vehicle parameters, shape ``(n_vehicles,)``.
428    method : {"trapezoid", "simpson"}
429        Integration rule.
430    chunk_size : int or None, optional
431        Number of vehicles processed together. ``None`` processes all at
432        once, which makes temporary arrays (and memory use) grow with the
433        number of vehicles. Any chunk size gives identical results; the
434        fastest depends on the CPU cache. See :data:`DEFAULT_CHUNK_SIZE`.
435
436    Returns
437    -------
438    dict of str to numpy.ndarray
439        ``e_pos_j`` and ``e_neg_j`` (J, per vehicle), plus ``dist_m`` and
440        ``duration_s`` (same for every vehicle, broadcast to the same shape).
441    """
442    mass_kg, f0, f1, f2 = (np.atleast_1d(np.asarray(x, dtype=float)) for x in (mass_kg, f0, f1, f2))
443    n = len(mass_kg)
444    if chunk_size is not None and chunk_size < 1:
445        raise ValueError("chunk_size must be at least 1, or None.")
446    step = n if chunk_size is None else chunk_size
447    accel = finite_difference_acceleration(cycle.speed_mps, cycle.dt)
448    e_pos = np.empty(n)
449    e_neg = np.empty(n)
450    for start in range(0, n, max(step, 1)):
451        sl = slice(start, start + step)
452        p_w = wheel_power(cycle.speed_mps, accel, mass_kg[sl], f0[sl], f1[sl], f2[sl])
453        e_pos[sl] = integrate(np.maximum(p_w, 0.0), cycle.dt, method)
454        e_neg[sl] = integrate(np.maximum(-p_w, 0.0), cycle.dt, method)
455    return {
456        "e_pos_j": e_pos,
457        "e_neg_j": e_neg,
458        "dist_m": np.full(n, float(integrate(cycle.speed_mps, cycle.dt, method))),
459        "duration_s": np.full(n, cycle.duration_s),
460    }

463def add_physics_features(
464    vehicles: pd.DataFrame,
465    cycles: dict[str, DriveCycle],
466    method: str = "trapezoid",
467) -> pd.DataFrame:
468    """Add per-cycle physics terms as columns of the vehicle table.
469
470    For each cycle name ``k`` in ``cycles`` the columns ``k_e_pos_j``,
471    ``k_e_neg_j``, ``k_dist_m`` and ``k_duration_s`` are added.
472
473    Parameters
474    ----------
475    vehicles : pandas.DataFrame
476        Cleaned table with ``etw_kg``, ``f0_n``, ``f1_n_per_mps`` and
477        ``f2_n_per_mps2``.
478    cycles : dict of str to DriveCycle
479        Typically from :func:`load_epa_cycles`.
480    method : {"trapezoid", "simpson"}
481        Integration rule.
482
483    Returns
484    -------
485    pandas.DataFrame
486        Copy of ``vehicles`` with the new columns.
487    """
488    out = vehicles.copy()
489    for name, cycle in cycles.items():
490        terms = cycle_energy_terms(
491            cycle,
492            out["etw_kg"].to_numpy(),
493            out["f0_n"].to_numpy(),
494            out["f1_n_per_mps"].to_numpy(),
495            out["f2_n_per_mps2"].to_numpy(),
496            method,
497        )
498        for key, values in terms.items():
499            out[f"{name}_{key}"] = values
500    return out

503def consumption_kwh_per_100mi(
504    e_pos_j: np.ndarray,
505    e_neg_j: np.ndarray,
506    duration_s: np.ndarray,
507    dist_m: np.ndarray,
508    eta_d: float,
509    eta_r: float,
510    p_aux_w: float,
511) -> np.ndarray:
512    """Evaluate ``c = (E_pos/eta_d - eta_r E_neg + P_aux T) / D`` in kWh/100 mi.
513
514    Parameters
515    ----------
516    e_pos_j, e_neg_j : numpy.ndarray
517        Positive and braking wheel energy over the cycle [J].
518    duration_s : numpy.ndarray
519        Cycle duration [s].
520    dist_m : numpy.ndarray
521        Cycle distance [m].
522    eta_d : float
523        Wall-to-wheel driving efficiency, in (0, 1].
524    eta_r : float
525        Fraction of braking energy recovered, in [0, 1].
526    p_aux_w : float
527        Accessory power [W].
528
529    Returns
530    -------
531    numpy.ndarray
532        Consumption in kWh/100 mi.
533
534    Examples
535    --------
536    >>> # 10 MJ positive, no braking, no aux, perfect efficiency, 160.9344 km:
537    >>> c = consumption_kwh_per_100mi(1e7, 0.0, 0.0, 160934.4, 1.0, 0.0, 0.0)
538    >>> round(float(c), 4)
539    2.7778
540    """
541    if not 0 < eta_d <= 1:
542        raise ValueError("eta_d must be in (0, 1].")
543    e_b = np.asarray(e_pos_j) / eta_d - eta_r * np.asarray(e_neg_j) + p_aux_w * np.asarray(duration_s)
544    return e_b / np.asarray(dist_m) * J_PER_M_TO_KWH_PER_100MI

552class PhysicsModel:
553    """Physics model with three parameters fitted by bounded least squares.
554
555    The model is fitted jointly on the city and highway results, so one set
556    of ``eta_d``, ``eta_r`` and ``P_aux`` describes both cycles.
557
558    Dividing the energy equation by distance gives, per vehicle and cycle,
559
560        c = k1 (E_pos/D) - k2 (E_neg/D) + k3 (T/D)
561
562    with ``k1 = 1/eta_d``, ``k2 = eta_r`` and ``k3 = P_aux``. The bounds
563    ``k1 >= 1``, ``0 <= k2 <= 1`` and ``k3 >= 0`` keep every parameter
564    physically meaningful.
565
566    Parameters
567    ----------
568    cycles : tuple of str, optional
569        Cycle name prefixes used in the feature columns.
570
571    Attributes
572    ----------
573    eta_d_, eta_r_, p_aux_w_ : float
574        Fitted parameters (available after :meth:`fit`).
575    """
576
577    def __init__(self, cycles: tuple[str, ...] = ("city", "hwy")):
578        self.cycles = cycles
579
580    def _design(self, df: pd.DataFrame, cycle: str) -> np.ndarray:
581        dist = df[f"{cycle}_dist_m"].to_numpy()
582        scale = J_PER_M_TO_KWH_PER_100MI
583        return np.column_stack(
584            [
585                df[f"{cycle}_e_pos_j"].to_numpy() / dist * scale,
586                -df[f"{cycle}_e_neg_j"].to_numpy() / dist * scale,
587                df[f"{cycle}_duration_s"].to_numpy() / dist * scale,
588            ]
589        )

238def finite_difference_acceleration(speed: np.ndarray, dt: float) -> np.ndarray:
239    """Differentiate a uniformly sampled speed trace.
240
241    Interior points use the second-order central difference
242    ``a_i = (v_{i+1} - v_{i-1}) / (2 dt)``. The first and last points use
243    first-order forward and backward differences.
244
245    Parameters
246    ----------
247    speed : numpy.ndarray
248        Speed samples, shape ``(n,)`` with ``n >= 2``.
249    dt : float
250        Time step.
251
252    Returns
253    -------
254    numpy.ndarray
255        Acceleration at every sample, shape ``(n,)``.
256
257    Examples
258    --------
259    >>> finite_difference_acceleration(np.array([0.0, 1.0, 4.0, 9.0]), 1.0)
260    array([1., 2., 4., 5.])
261    """
262    speed = np.asarray(speed, dtype=float)
263    if speed.size < 2:
264        raise ValueError("Need at least two samples to differentiate.")
265    accel = np.empty_like(speed)
266    accel[1:-1] = (speed[2:] - speed[:-2]) / (2.0 * dt)
267    accel[0] = (speed[1] - speed[0]) / dt
268    accel[-1] = (speed[-1] - speed[-2]) / dt
269    return accel

422

424    ----------
425    cycle : DriveCycle

427    mass_kg, f0, f1, f2 : numpy.ndarray
428        Vehicle parameters, shape ``(n_vehicles,)``.
429    method : {"trapezoid", "simpson"}
430        Integration rule.
431    chunk_size : int or None, optional
432        Number of vehicles processed together. ``None`` processes all at
433        once, which makes temporary arrays (and memory use) grow with the

435        fastest depends on the CPU cache. See :data:`DEFAULT_CHUNK_SIZE`.

438    -------
439    dict of str to numpy.ndarray

442    """
443    mass_kg, f0, f1, f2 = (np.atleast_1d(np.asarray(x, dtype=float)) for x in (mass_kg, f0, f1, f2))
444    n = len(mass_kg)
445    if chunk_size is not None and chunk_size < 1:
446        raise ValueError("chunk_size must be at least 1, or None.")

448    accel = finite_difference_acceleration(cycle.speed_mps, cycle.dt)
449    e_pos = np.empty(n)

451    for start in range(0, n, max(step, 1)):

461    }

555
556    The model is fitted jointly on the city and highway results, so one set
557    of ``eta_d``, ``eta_r`` and ``P_aux`` describes both cycles.
558

565    physically meaningful.

587                -df[f"{cycle}_e_neg_j"].to_numpy() / dist * scale,

594

600
601        Returns
602        -------
